# 📸 Scrolling Images

A simple web page that displays a list of images inside a 9:16 container.  
Users can scroll through the images **one by one** by clicking a button.  
When the last image is reached, it automatically loops back to the first image.

---

## 🚀 Features
- Smooth scroll animation for each image.
- Automatically loops back to the first image after the last one.
- Clean and minimal 9:16 screen-style layout.
- Fully responsive and works on all browsers.

---

## 🧠 How It Works
- All images are placed inside a `.images` container.
- When the **"Scroll"** button is clicked:
  1. The JavaScript function increases an index counter.
  2. The container scrolls smoothly to the next image.
  3. When the last image is reached, the index resets to `0`, returning to the top.

---

## 🧩 Technologies Used
- **HTML5**
- **CSS3**
- **JavaScript (ES6)**

---

## 🖥️ How to Run
1. Clone or download the repository.  
2. Make sure `index.html`, `style3.css`, and `script3.js` are in the same folder.  
3. Open `index.html` in your browser.  
4. Click the **"Scroll"** button to see the animation.
